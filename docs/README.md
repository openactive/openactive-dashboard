# Docs

This folder explains how the OpenActive dashboard is put together. It is meant for anyone working in this repository.

Start with the root README for how to run the app and come here when you need to know how a part of the code works.

- `architecture.md` — how the app is laid out and how data moves through it
- `monitor-api.md` — the Monitor API calls this app makes
- `landing.md` — the hero and the summary numbers at the top of the page
- `opportunities.md` — what an opportunity is and how we add the numbers up
- `explorer-filters.md` — location, activity, provider and publisher filters
- `explorer-map.md` — the map, boundaries and area counts
- `explorer-summary.md` — the stats panel, mobile layout and details modal
- `socio.md` — population, deprivation and Active Lives
- `feed-quality.md` — the feed quality table and how it follows the explorer
- `glossary.md` — tooltip wording
- `testing.md` — tests, fixtures and CI
